# RentSmart — Sistema de Orçamento de Locação (R.M Imóveis)

Aplicação em Python desenvolvida com Programação Orientada a Objetos (POO) para automatizar o cálculo de locações, adicionais, descontos, parcelamento de taxa contratual e projeção de 12 meses em CSV.

## Requisitos
- Python 3.10 ou superior (não requer bibliotecas externas).
